# SMART BUS MANAGEMENT SYSTEM (Frontend MVP)

Frontend-only prototype for Vignan University transportation management using React + Vite + Tailwind + React Router + Leaflet/OpenStreetMap with mock data.

## Run

```bash
npm install
npm run dev
```

## Demo login

- Student: `student@vignan.edu` / `student123`
- Driver: `driver@vignan.edu` / `driver123`
- Admin: `admin@vignan.edu` / `admin123`

All data, map routes, and bus locations are **demo/sample data only**.
